# Contexto Geral
Em 2023, o PETCode idealizou e executou a oferta de oficinas de Joomla para grupos acadêmicos da FURG. O foco era dar autonomia para que outros projetos e PETs administrassem seus próprios sites institucionais.

# Histórico de Execução
Foram realizadas um total de três oficinas:
1. No IMEF, focada no grupo PETSabEst (23 de junho de 2023).
2. No Instituto de Educação.
3. No SEURS, em Ponta Grossa.

# Motivo da Descontinuação
O projeto foi oficialmente encerrado pois a Universidade Federal do Rio Grande (FURG) parou de utilizar o sistema Joomla como base para seus portais institucionais, tornando a ferramenta obsoleta para o contexto local.

# Contexto Geral
Seguindo o pilar de Ensino do grupo, o PETCode desenvolve materiais didáticos (apostilas) focados em linguagens de programação e tecnologias de infraestrutura. O objetivo é criar uma base sólida para iniciantes na jornada acadêmica.

# Processo de Criação de uma Nova Apostila
Para padronizar e facilitar a produção de novos materiais, os petianos devem seguir as etapas abaixo:
1. **Escrita e Rascunho:** O texto e os códigos da apostila devem ser escritos e revisados colaborativamente utilizando o Microsoft Word ou o Google Docs.
2. **Design e Diagramação:** Após a revisão do texto, o conteúdo deve ser passado para o Canva. É obrigatório utilizar o padrão de design visual do PET C3 para manter a coesão entre os materiais.
   *(Link do template padrão no Canva: [INSERIR LINK DO CANVA AQUI])*
3. **Exportação:** Finalizado o design, o arquivo deve ser exportado no formato PDF.
4. **Publicação no Site:** O petiano responsável deve adicionar o PDF na pasta do site e criar o respectivo card na página de apostilas (seguindo o tutorial de manutenção do `Site_Oficial_PET_C3.md`).

# Apostilas Finalizadas e Disponíveis
Até o momento, o acervo conta com 5 apostilas oficiais desenvolvidas pelos petianos:
1. **Python:** Lógica básica, sintaxe e introdução a bibliotecas.
2. **C / C++:** Fundamentos da programação estruturada e orientada a objetos.
3. **HTML e CSS:** Introdução ao desenvolvimento web e estilização (Front-end).
4. **Linux:** Comandos básicos, terminal e uso do sistema operacional.
5. **Arduino:** Eletrônica básica, prototipagem e programação de microcontroladores.
